@EntityGraph 추가 과제

과제 1: CourseRepository.findByInstructor()

쉬움

CourseRepository의 findByInstructor() 메서드에 @EntityGraph를 추가하여 instructor 정보를 함께 조회하도록 개선하세요.

// 현재 코드 List<Course> findByInstructor(User instructor); // 개선 후 @EntityGraph(attributePaths = {"instructor"}) List<Course> findByInstructor(User instructor);

과제 2: EnrollmentRepository.findByCourseAndStatusForUpdate()

쉬움

EnrollmentRepository의 findByCourseAndStatusForUpdate() 메서드에 @EntityGraph를 추가하여 student와 course 정보를 함께 조회하도록 개선하세요.

// 현재 코드 @Lock(LockModeType.PESSIMISTIC_WRITE) List<Enrollment> findByCourseAndStatusForUpdate(Course course, EnrollmentStatus status); // 개선 후 @Lock(LockModeType.PESSIMISTIC_WRITE) @EntityGraph(attributePaths = {"student", "course"}) List<Enrollment> findByCourseAndStatusForUpdate(Course course, EnrollmentStatus status);

UI 구현 과제

과제 4: 관리자 수강신청 관리 페이지

보통

관리자가 여러 수강신청을 선택하여 일괄 승인/거절할 수 있는 페이지를 구현하세요.

구현 요구사항:

  • • 체크박스로 여러 수강신청 선택
  • • "일괄 승인" / "일괄 거절" 버튼
  • • 처리 사유 입력 필드 (선택 사항)
  • • 배치 처리 결과 모달/알림
  • • 성공/실패 통계 및 실패 목록 표시

과제 5: 강의별 수강신청 관리

보통

강의 상세 페이지에서 해당 강의의 모든 대기 중인 수강신청을 일괄 처리할 수 있는 기능을 구현하세요.

구현 요구사항:

  • • 강의 상세 페이지에 "전체 승인" / "전체 거절" 버튼 추가
  • • 해당 강의의 모든 대기 중인 수강신청 일괄 처리
  • • 처리 사유 입력 필드 (선택 사항)
  • • 처리 결과 모달/알림

과제 6: 배치 처리 결과 모달

어려움

배치 처리 후 결과를 보여주는 모달을 구현하세요.

구현 요구사항:

  • • 전체 처리 건수, 성공 건수, 실패 건수 표시
  • • 실패한 수강신청 목록 및 실패 사유 표시
  • • 성공한 수강신청 목록 표시 (선택 사항)
  • • 모달 닫기 버튼
  • • 실패 목록 다운로드 기능 (선택 사항)

성능 테스트 과제

과제 9: N+1 문제 확인

보통

N+1 문제가 발생하는지 확인하고 해결하세요.

확인 방법:

  • • application-jpa.properties에서 show-sql=true 설정
  • • Course 목록 조회 후 각 Course의 curriculums 접근
  • • Enrollment 목록 조회 후 각 Enrollment의 student, course 접근
  • • N+1 문제 발견 시 @EntityGraph로 해결
