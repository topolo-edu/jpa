실무 활용 가이드

1. 배포 직후 서버 상태 확인

AWS EC2에 배포했다면 브라우저에서:

http://서버주소:8080/actuator/health

✅ {"status":"UP"} 이 나오면 서버 정상
❌ 연결 안 됨 → 포트 8080 방화벽 확인

2. 메모리 누수 의심될 때

같은 페이지를 10~20번 새로고침 후:

/actuator/metrics/jvm.memory.used

정상: 메모리 사용량이 비슷
문제: 계속 증가 → 메모리 누수 가능성

3. 느린 API 찾는 방법

⚠️ 주의: 위 "HTTP Requests" 카드는 전체 평균만 보여줍니다.
어느 API가 느린지는 알 수 없습니다.

실제 느린 API 찾는 방법:

방법 1 (추천): 브라우저 개발자 도구
• F12 → Network 탭
• 페이지 새로고침
• Time 컬럼에서 느린 요청 확인

방법 2: Postman으로 API 하나씩 테스트
• 각 API 호출 후 우측 하단 시간 확인
• 300ms 이상이면 느린 편

방법 3 (고급): 애플리케이션 로그
• logging.level.org.springframework.web=DEBUG
• 콘솔에서 각 요청의 처리 시간 확인

개선 방법: N+1 쿼리, Fetch Join 확인

4. 운영 환경 보안 설정

실제 운영 서버에서는 Actuator URL 변경:

# application-prod.properties
management.endpoints.web.base-path=/internal-monitor
management.server.port=9090

효과: /actuator → /internal-monitor
포트도 8080 → 9090으로 분리 (외부 차단)
