✨ 신규 엔드포인트

Step 2에서 양방향 관계를 통해 새롭게 추가된 엔드포인트입니다.

⚡ 수강신청 배치 처리 (신규)

Method Endpoint 기능 적용 기술
POST /api/enrollments/batch 여러 수강신청 일괄 승인/거절 비관적 락
POST /api/enrollments/batch/course/{courseNo} 강의별 수강신청 일괄 처리 비관적 락

📚 강의 커리큘럼 (Course ↔ Curriculum 양방향)

Method Endpoint 기능 적용 기술
GET /api/courses/{courseNo}/curriculums 강의별 커리큘럼 목록 조회 @OneToMany

👥 수강생 목록 (Course ↔ Enrollment 양방향)

Method Endpoint 기능 적용 기술
GET /api/courses/{courseNo}/students 수강생 목록 조회 (승인된 학생) @OneToMany

🎯 주요 변경 사항

1. 양방향 관계 추가

  • • Course ↔ Curriculum: @OneToMany 양방향
  • • Course ↔ Enrollment: @OneToMany 양방향
  • • User ↔ Enrollment: @OneToMany 양방향

2. 편의 메소드

  • • course.addCurriculum(curriculum)
  • • course.addEnrollment(enrollment)
  • • user.addEnrollment(enrollment)
  • • 양쪽 참조를 자동으로 설정하여 일관성 유지

3. Cascade 적용

  • • CascadeType.ALL: 모든 연산 자동 전파
  • • Course 삭제 시 Curriculum, Enrollment 자동 삭제
  • • User 삭제 시 Enrollment 자동 삭제

4. 고아 객체 제거

  • • orphanRemoval = true
  • • 컬렉션에서 제거된 엔티티 자동 삭제
  • • 예: course.removeCurriculum(curriculum) → DB에서 삭제
