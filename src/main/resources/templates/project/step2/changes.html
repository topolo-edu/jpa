🎯 주요 변경 사항

1. 양방향 관계 (Aggregate 내부)

  • ✅ Course ↔ Curriculum: 양방향 + Cascade + orphanRemoval
  • ⚡ Enrollment → User/Course: 단방향 (Repository로 역방향 조회)
  • • Aggregate 패턴 기반 설계 원칙 적용

2. 편의 메서드 (Course ↔ Curriculum)

  • • course.addCurriculum()
  • • course.removeCurriculum()
  • • 양방향 관계 동기화 자동 처리

3. Cascade (Aggregate 내부만)

  • • CascadeType.ALL: Course → Curriculum만 적용
  • • Course 삭제 시 Curriculum 자동 삭제
  • ⚠️ Enrollment는 독립 생명주기 (Cascade 없음)

4. 동시성 제어 + 배치 처리

  • • 비관적 락 (Pessimistic Lock) 적용
  • • 독립 트랜잭션 (REQUIRES_NEW) 배치 처리
  • • 부분 성공/실패 지원
