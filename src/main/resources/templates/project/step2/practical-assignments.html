📋 과제 1. 수강신청 배치 처리 UI

난이도: 하

목표

관리자가 여러 수강신청을 한 번에 승인/거절할 수 있는 UI를 구현합니다.

준비된 API

POST /api/enrollments/batch
Request Body: 
{
  "enrollmentIds": [1, 2, 3, 4, 5],
  "action": "APPROVE",  // 또는 "REJECT"
  "reason": "일괄 승인"
}
POST /api/enrollments/batch/course/{courseNo}
Query Parameters: action=APPROVE&reason=정원확인완료

구현 체크리스트

  • 1단계: /enrollment/manage 페이지에 체크박스 추가
  • 2단계: "일괄 승인" / "일괄 거절" 버튼 추가
  • 3단계: 체크된 항목의 ID 수집 후 API 호출
  • 4단계: 처리 결과 모달/알림으로 표시 (성공/실패 개수)
  • 5단계: 실패한 항목과 사유 표시

구현 힌트

HTML (체크박스 추가):

<!-- 테이블 헤더에 전체 선택 체크박스 --> <th> <input type="checkbox" id="selectAll"> </th> <!-- 각 행에 개별 체크박스 --> <td> <input type="checkbox" class="enrollment-checkbox" th:value="${enrollment.enrollmentNo}"> </td>

JavaScript (배치 처리):

function batchApprove() { // 1. 체크된 항목의 ID 수집 const checkedIds = Array.from( document.querySelectorAll('.enrollment-checkbox:checked') ).map(cb => parseInt(cb.value)); if (checkedIds.length === 0) { alert('선택된 항목이 없습니다'); return; } // 2. API 호출 fetch('/api/enrollments/batch', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ enrollmentIds: checkedIds, action: 'APPROVE', reason: '일괄 승인' }) }) .then(response => response.json()) .then(data => { // 3. 결과 표시 showResultModal(data.data); }); }

💡 추가 도전: 강의 상세 페이지에서 "이 강의의 대기 중인 신청 전체 승인" 버튼 추가해보세요! /api/enrollments/batch/course/{courseNo} API를 사용합니다.

📚 과제 2. 강의 커리큘럼 팝업

난이도: 하

목표

강의 상세 페이지에서 "커리큘럼 보기" 버튼을 클릭하면 커리큘럼 목록을 팝업으로 표시합니다.

준비된 API

GET /api/courses/{courseNo}/curriculums
Response: 
{
  "success": true,
  "data": [
    {
      "curriculumNo": 1,
      "weekNumber": 1,
      "title": "JPA 소개",
      "description": "JPA 기본 개념",
      "materials": "교재 1장",
      "duration": 120
    }
  ]
}

구현 체크리스트

  • 1단계: 강의 상세 페이지에 "커리큘럼 보기" 버튼 추가
  • 2단계: 버튼 클릭 시 API 호출하여 데이터 가져오기
  • 3단계: 모달/팝업 UI 구현
  • 4단계: 주차별로 정렬하여 표시
  • 5단계: 소요시간(duration)을 "시간 분" 형식으로 표시

구현 힌트

모달 HTML 템플릿:

<!-- 모달 HTML --> <div id="curriculumModal" class="modal"> <div class="modal-content"> <span class="close">×</span> <h2>커리큘럼</h2> <div id="curriculumList"> <!-- 동적으로 생성 --> </div> </div> </div>

JavaScript:

function showCurriculums(courseNo) { fetch(`/api/courses/${courseNo}/curriculums`) .then(response => response.json()) .then(data => { const curriculums = data.data; const html = curriculums.map(c => ` <div class="curriculum-item"> <h3>${c.weekNumber}주차: ${c.title}</h3> <p>${c.description}</p> <small>소요시간: ${formatDuration(c.duration)}</small> </div> `).join(''); document.getElementById('curriculumList').innerHTML = html; document.getElementById('curriculumModal').style.display = 'block'; }); } function formatDuration(minutes) { const hours = Math.floor(minutes / 60); const mins = minutes % 60; return hours > 0 ? `${hours}시간 ${mins}분` : `${mins}분`; }

👥 과제 3. 수강생 목록 팝업

난이도: 중

목표

강의 상세 페이지에서 "수강생 보기" 버튼을 클릭하면 승인된 수강생 목록을 표시합니다. 추가로 각 수강생의 프로필 정보도 표시합니다.

준비된 API

GET /api/courses/{courseNo}/students
Response: 
{
  "success": true,
  "data": [
    {
      "userNo": 1,
      "username": "student1",
      "fullName": "홍길동",
      "email": "hong@example.com",
      "role": "STUDENT",
      "profileImageUrl": "/images/profile/default.png"
    }
  ]
}

구현 체크리스트

  • 1단계: 강의 상세 페이지에 "수강생 보기 (N명)" 버튼 추가
  • 2단계: API 호출하여 수강생 목록 가져오기
  • 3단계: 프로필 이미지, 이름, 이메일을 카드 형식으로 표시
  • 4단계: 수강생이 없으면 "아직 수강생이 없습니다" 표시
  • 5단계: 반응형 그리드 레이아웃 구현 (2~4열)

구현 힌트

function showStudents(courseNo) { fetch(`/api/courses/${courseNo}/students`) .then(response => response.json()) .then(data => { const students = data.data; if (students.length === 0) { showEmptyState(); return; } const html = students.map(s => ` <div class="student-card"> <img src="${s.profileImageUrl}" alt="${s.fullName}"> <h4>${s.fullName}</h4> <p>${s.email}</p> </div> `).join(''); showModal(html); }); }

CSS 힌트 (Grid Layout):

.students-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)); gap: 1rem; } .student-card { text-align: center; padding: 1rem; border: 1px solid #ddd; border-radius: 8px; } .student-card img { width: 80px; height: 80px; border-radius: 50%; object-fit: cover; }

🎨 디자인 팁: 승인된 수강생만 표시되므로, "승인 완료 ✓" 뱃지를 추가하면 좋습니다. 대기/거절 상태는 표시되지 않으니 주의하세요!

📊 과제 4. 강의 통계 대시보드 (선택)

난이도: 상

목표

관리자 대시보드에서 강의 통계를 시각화합니다. Chart.js 또는 다른 차트 라이브러리를 사용해보세요!

준비된 API

GET /api/dashboard/course-statistics
전체 강의 통계
GET /api/dashboard/course-statistics/details
강의별 상세 통계
GET /api/dashboard/course-statistics/instructor
강사별 통계

구현 체크리스트

  • 1단계: Chart.js 라이브러리 추가
  • 2단계: 전체 통계 카드 표시 (총 강의 수, 총 수강생 등)
  • 3단계: 강의별 수강률을 바 차트로 표시
  • 4단계: 강사별 강의 수를 원 차트로 표시
  • 5단계: 월별 개설 추이를 라인 차트로 표시

구현 힌트

Chart.js 설치:

<!-- CDN으로 추가 --> <script src="https://cdn.jsdelivr.net/npm/chart.js"></script>

바 차트 예제:

fetch('/api/dashboard/course-statistics/details') .then(response => response.json()) .then(data => { const ctx = document.getElementById('courseChart').getContext('2d'); new Chart(ctx, { type: 'bar', data: { labels: data.data.map(c => c.courseName), datasets: [{ label: '수강률 (%)', data: data.data.map(c => c.enrollmentRatio), backgroundColor: 'rgba(59, 130, 246, 0.5)' }] } }); });

⚠️ 난이도 높음: 이 과제는 Chart.js 사용법을 알아야 합니다. 시간이 부족하면 간단한 테이블 형식으로 먼저 구현 후, 나중에 차트로 업그레이드하세요!

⚡ 과제 5. @EntityGraph 추가 적용 (선택)

난이도: 중

목표

아직 JPQL Fetch Join을 사용하는 Repository 메서드를 @EntityGraph로 개선합니다.

적용 대상

  • CourseRepository.findByInstructor() - instructor 포함
  • EnrollmentRepository.findByCourseAndStatusForUpdate() - course, student 포함
  • CourseRepository.searchAvailableCourses() - instructor 포함

구현 힌트

BEFORE (JPQL Fetch Join):

@Query(""" SELECT c FROM Course c JOIN FETCH c.instructor WHERE c.instructor = :instructor """) Page<Course> findByInstructor(@Param("instructor") User instructor, Pageable pageable);

AFTER (@EntityGraph):

@EntityGraph(attributePaths = {"instructor"}) @Query(""" SELECT c FROM Course c WHERE c.instructor = :instructor """) Page<Course> findByInstructor(@Param("instructor") User instructor, Pageable pageable);

✅ 장점: 코드가 더 간결하고, Fetch Join을 명시할 필요 없음!
