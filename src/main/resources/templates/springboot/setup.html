접속 및 설정

Project Metadata

Language Java

Dependencies (추천)

  • Spring Web - REST API 개발
  • Spring Data JPA - JPA 데이터 액세스
  • H2 Database - 내장 DB (개발용)
  • Lombok - 보일러플레이트 코드 제거
  • Validation - 입력값 검증
  • Spring Boot DevTools - 자동 재시작

레이어별 역할

Controller (컨트롤러)

HTTP 요청 받기 → Service 호출 → 응답 반환
@RestController, @Controller

Service (서비스)

비즈니스 로직 처리 → Repository 호출
@Service

Repository (레포지토리)

DB 접근 (CRUD) → Entity 매핑
@Repository, JpaRepository

Model/Entity (모델)

DB 테이블과 매핑되는 클래스
@Entity, @Table

DTO (데이터 전송 객체)

클라이언트 ↔ 서버 데이터 전송용
일반 POJO 클래스
