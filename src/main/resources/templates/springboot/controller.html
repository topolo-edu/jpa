Controller 레이어

HTTP 요청을 받아 처리하고 응답을 반환하는 Controller의 어노테이션을 학습합니다

@Controller vs @RestController

@Controller

뷰(View) 템플릿을 반환하는 전통적인 MVC 컨트롤러
Thymeleaf, JSP 등 HTML 페이지 렌더링 

@Controller
public class OrderController {

    @GetMapping("/orders")
    public String list(Model model) {
        model.addAttribute("orders", orders);
        return "order/list"; // HTML 뷰 이름
    }
}
용도: 서버 사이드 렌더링 (SSR), 웹 페이지 반환

@RestController

JSON/XML 데이터를 반환하는 REST API 컨트롤러
@Controller + @ResponseBody 합친 것 

@RestController
public class OrderApiController {

    @GetMapping("/api/orders")
    public List<Order> list() {
        return orders; // 자동으로 JSON 변환
    }
}
용도: REST API, JSON 응답 (React, Vue 등 프론트엔드)

예제: REST API 컨트롤러 

@RestController
@RequestMapping("/api/orders")
@RequiredArgsConstructor
public class OrderController {

    private final OrderService orderService;

    // 1. 전체 조회 (GET /api/orders)
    @GetMapping
    public List<Order> getAllOrders() {
        return orderService.findAll();
    }

    // 2. 단건 조회 (GET /api/orders/1)
    @GetMapping("/{id}")
    public Order getOrder(@PathVariable Long id) {
        return orderService.findById(id);
    }

    // 3. 생성 (POST /api/orders)
    @PostMapping
    public Order createOrder(@RequestBody @Valid OrderRequest request) {
        return orderService.create(request);
    }

    // 4. 수정 (PUT /api/orders/1)
    @PutMapping("/{id}")
    public Order updateOrder(@PathVariable Long id,
                                  @RequestBody OrderRequest request) {
        return orderService.update(id, request);
    }

    // 5. 삭제 (DELETE /api/orders/1)
    @DeleteMapping("/{id}")
    public void deleteOrder(@PathVariable Long id) {
        orderService.delete(id);
    }

    // 6. 검색 (GET /api/orders/search?name=홍길동)
    @GetMapping("/search")
    public List<Order> searchOrders(@RequestParam String name) {
        return orderService.findByCustomerName(name);
    }
}

Controller 어노테이션 정리

그룹 1 클래스 레벨 어노테이션

어노테이션 설명 예시
@RestController REST API 컨트롤러
JSON 응답 자동 변환		 @RestController
@Controller View 템플릿 컨트롤러
HTML 페이지 반환		 @Controller
@RequestMapping 공통 URL 경로 매핑
클래스에 붙이면 모든 메서드에 적용		 @RequestMapping("/api/orders")
@RequiredArgsConstructor 의존성 주입 생성자 자동 생성
Lombok, final 필드용		 @RequiredArgsConstructor

그룹 2 HTTP 메서드 매핑 어노테이션

어노테이션 설명 예시
@GetMapping 조회 요청 (GET)
데이터 조회, 읽기 전용		 @GetMapping("/orders")
@PostMapping 생성 요청 (POST)
새 데이터 생성		 @PostMapping("/orders")
@PutMapping 수정 요청 (PUT)
전체 데이터 수정		 @PutMapping("/orders/{id}")
@PatchMapping 부분 수정 (PATCH)
일부 필드만 수정		 @PatchMapping("/orders/{id}")
@DeleteMapping 삭제 요청 (DELETE)
데이터 삭제		 @DeleteMapping("/orders/{id}")

그룹 3 파라미터 바인딩 어노테이션

어노테이션 설명 예시
@PathVariable URL 경로의 변수 추출
/orders/{id} → id 값 가져오기		 @PathVariable Long id
@RequestParam 쿼리 파라미터 추출
/search?name=홍길동 → name 값		 @RequestParam String name
@RequestBody HTTP Body의 JSON을 객체로 변환
POST/PUT 요청의 데이터		 @RequestBody OrderRequest req
@ModelAttribute 폼 데이터를 객체로 바인딩
HTML form 전송 데이터		 @ModelAttribute OrderForm form

그룹 4 응답 처리 어노테이션

어노테이션 설명 예시
@ResponseBody 응답을 JSON으로 변환
@RestController는 자동 적용		 @ResponseBody
@ResponseStatus HTTP 상태 코드 지정
201 Created, 204 No Content 등		 @ResponseStatus(HttpStatus.CREATED)
ResponseEntity 상태코드 + 헤더 + 바디 포함 응답
유연한 응답 커스터마이징		 return ResponseEntity.ok(order);

그룹 5 유효성 검증 어노테이션

어노테이션 설명 예시
@Valid 객체 유효성 검증 활성화
DTO 클래스의 @NotNull 등 검증		 @Valid @RequestBody OrderRequest
@Validated 그룹별 유효성 검증
Spring 제공, 그룹 지정 가능		 @Validated(CreateGroup.class)

@Controller에서 JSON 응답하려면? 

@Controller
public class OrderController {

    @GetMapping("/api/orders")
    @ResponseBody  // 이 어노테이션 추가!
    public List<Order> getOrders() {
        return orders; // JSON으로 변환됨
    }
}

@ResponseBody를 메서드에 추가하면 JSON 응답 가능!
하지만 API가 많으면 @RestController 사용이 편리합니다.

실무 팁

권장사항

  • • RESTful URL 설계: /api/orders, /api/orders/{id}
  • • DTO 사용: Entity 직접 반환 지양
  • • @Valid 활용: 입력값 검증 필수
  • • ResponseEntity: 상태코드 명시적 반환

주의사항

  • • Entity 직접 반환 금지: 순환참조, 보안 문제
  • • 예외 처리: @ControllerAdvice로 전역 처리
  • • CORS 설정: 프론트엔드 분리 시 필수
  • • 버전 관리: /api/v1/orders 형태 권장
