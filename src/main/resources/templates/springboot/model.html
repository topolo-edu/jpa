Model/Entity 레이어

데이터베이스 테이블과 매핑되는 Entity 클래스의 JPA 어노테이션을 학습합니다

예제: Order 엔티티 

@Entity
@Table(name = "orders")
@Getter @Setter
@NoArgsConstructor
public class Order {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 100)
    private String customerName;

    @Column(name = "order_date")
    private LocalDateTime orderDate;

    @Enumerated(EnumType.STRING)
    private OrderStatus status;

    @OneToMany(mappedBy = "order", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<OrderItem> items = new ArrayList<>();

    @CreatedDate
    private LocalDateTime createdAt;

    @LastModifiedDate
    private LocalDateTime updatedAt;

    // 비즈니스 메서드
    public void addItem(OrderItem item) {
        items.add(item);
        item.setOrder(this);
    }
}

예제: OrderItem 엔티티 

@Entity
@Table(name = "order_items")
@Getter @Setter
@NoArgsConstructor
public class OrderItem {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "order_id", nullable = false)
    private Order order;

    @Column(nullable = false)
    private String productName;

    @Column(nullable = false)
    private Integer quantity;

    @Column(nullable = false)
    private BigDecimal price;

    // 계산 메서드
    public BigDecimal getTotalPrice() {
        return price.multiply(BigDecimal.valueOf(quantity));
    }
}

JPA 어노테이션 정리

그룹 1 기본 엔티티 어노테이션

어노테이션 설명 예시
@Entity JPA 엔티티 클래스임을 선언
필수 어노테이션		 @Entity public class Order { }
@Table 매핑할 테이블 이름 지정
생략 시 클래스명이 테이블명		 @Table(name = "orders")
@Id 기본키(Primary Key) 필드
필수 어노테이션		 @Id private Long id;
@GeneratedValue 기본키 자동 생성 전략
IDENTITY, SEQUENCE, AUTO		 @GeneratedValue(strategy = IDENTITY)

그룹 2 컬럼 매핑 어노테이션

어노테이션 설명 예시
@Column 컬럼 상세 설정
name, nullable, length 등		 @Column(nullable = false, length = 100)
@Enumerated Enum 타입 매핑
STRING 권장 (ORDINAL 위험)		 @Enumerated(EnumType.STRING)
@Temporal 날짜/시간 타입 매핑
Java 8 이후 LocalDateTime은 불필요		 @Temporal(TemporalType.TIMESTAMP)
@Lob 큰 데이터 저장 (BLOB, CLOB)
텍스트, 바이너리 대용량 데이터		 @Lob private String content;
@Transient DB 매핑 제외 필드
임시 계산용 필드		 @Transient private int temp;

그룹 3 연관관계 매핑 어노테이션

어노테이션 설명 예시
@OneToMany 일대다 관계 (1:N)
주문 1 : 주문아이템 N		 @OneToMany(mappedBy = "order")
@ManyToOne 다대일 관계 (N:1)
주문아이템 N : 주문 1 (연관관계 주인)		 @ManyToOne(fetch = LAZY)
@OneToOne 일대일 관계 (1:1)
회원 1 : 배송지 1		 @OneToOne(fetch = LAZY)
@ManyToMany 다대다 관계 (N:M)
실무에서는 중간 테이블로 풀어서 사용		 @ManyToMany (사용 비추천)
@JoinColumn 외래키 컬럼 지정
연관관계 주인 쪽에 사용		 @JoinColumn(name = "order_id")

그룹 4 영속성 전이 & 페치 전략

속성 설명 예시
cascade 부모 엔티티 변경 시 자식에 전이
ALL, PERSIST, REMOVE 등		 cascade = CascadeType.ALL
orphanRemoval 고아 객체 자동 삭제
부모와 연결 끊어지면 자동 DELETE		 orphanRemoval = true
fetch = LAZY 지연 로딩 (권장)
실제 사용 시점에 쿼리 실행		 @ManyToOne(fetch = LAZY)
fetch = EAGER 즉시 로딩 (N+1 위험)
엔티티 조회 시 즉시 JOIN 쿼리		 @ManyToOne(fetch = EAGER)
mappedBy 연관관계 주인 반대편 지정
읽기 전용, FK 관리 안 함		 @OneToMany(mappedBy = "order")

그룹 5 Lombok & Auditing 어노테이션

어노테이션 설명 예시
@Getter @Setter Getter/Setter 자동 생성
Lombok 라이브러리		 @Getter @Setter
@NoArgsConstructor 기본 생성자 자동 생성
JPA는 기본 생성자 필수		 @NoArgsConstructor
@AllArgsConstructor 모든 필드 포함 생성자
Lombok		 @AllArgsConstructor
@Builder 빌더 패턴 자동 생성
가독성 좋은 객체 생성		 Order.builder().name("홍길동").build()
@CreatedDate 생성 시간 자동 기록
JPA Auditing 기능		 @CreatedDate private LocalDateTime createdAt;
@LastModifiedDate 수정 시간 자동 기록
JPA Auditing 기능		 @LastModifiedDate private LocalDateTime updatedAt;

실무 팁

주의사항

  • • EAGER 로딩 지양: N+1 문제 발생 → LAZY 사용
  • • @ManyToMany 비추천: 중간 테이블로 풀어서 사용
  • • Enum은 STRING: ORDINAL은 순서 변경 시 오류
  • • 양방향 관계 주의: 연관관계 주인만 FK 관리

권장사항

  • • 기본 생성자 필수: JPA는 리플렉션 사용
  • • @Builder 활용: 가독성 좋은 객체 생성
  • • Auditing 활용: createdAt, updatedAt 자동화
  • • 비즈니스 로직 위치: Entity에 도메인 메서드 추가
