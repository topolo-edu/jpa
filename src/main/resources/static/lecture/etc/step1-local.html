1단계: 로컬 환경 구축

우분투 서버에서 JAR 파일 실행 환경 구성

개요 1단계: 로컬 2단계: Dockerfile 3단계: Compose 4단계: AWS 5단계: CI/CD

학습 목표

로컬 우분투 서버를 AWS EC2와 동일한 개념으로 이해하고, JAR 파일을 직접 실행하는 기본적인 배포 방식을 학습합니다.

  • • 우분투 서버 = AWS EC2 (가상 서버)
  • • 로컬 MariaDB = AWS RDS (관리형 데이터베이스)
  • • 파일시스템 = AWS S3 (객체 저장소)

1. 우분투 서버 설치

1

가상머신 또는 WSL2 설치

로컬에 우분투 서버 환경을 구축합니다.

방법 1: VirtualBox + Ubuntu

  • • VirtualBox 다운로드 및 설치
  • • Ubuntu Server 20.04/22.04 ISO 다운로드
  • • 가상머신 생성 (RAM 2GB, 디스크 20GB)
  • • 네트워크 설정 (NAT 또는 Bridge)

방법 2: WSL2 (Windows)

  • • Windows 기능에서 WSL 활성화
  • • Microsoft Store에서 Ubuntu 설치
  • • WSL2로 업그레이드
  • • 네트워크 포트 포워딩 설정

2. Java 환경 구성

2

OpenJDK 11 설치

Spring Boot 애플리케이션 실행을 위한 Java 환경을 구성합니다.

# 패키지 업데이트
sudo apt update

# OpenJDK 11 설치
sudo apt install openjdk-11-jdk

# Java 버전 확인
java -version

# JAVA_HOME 환경변수 설정
echo 'export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64' >> ~/.bashrc
echo 'export PATH=$JAVA_HOME/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

# 환경변수 확인
echo $JAVA_HOME

3. MariaDB 설치 및 설정

3

데이터베이스 환경 구성

애플리케이션에서 사용할 MariaDB를 설치하고 설정합니다.

# MariaDB 설치
sudo apt install mariadb-server

# MariaDB 서비스 시작
sudo systemctl start mariadb
sudo systemctl enable mariadb

# 보안 설정
sudo mysql_secure_installation

# 데이터베이스 및 사용자 생성
sudo mysql -u root -p

# MySQL 콘솔에서 실행
CREATE DATABASE jpa CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'jpa_user'@'localhost' IDENTIFIED BY 'jpa_password';
GRANT ALL PRIVILEGES ON jpa.* TO 'jpa_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;

4. JAR 파일 전송 및 실행

4

SFTP를 통한 파일 전송

로컬에서 빌드한 JAR 파일을 서버로 전송합니다.

Windows (WinSCP 사용)

# WinSCP로 연결
# 호스트: 서버 IP 주소
# 사용자명: ubuntu
# 비밀번호: 설정한 비밀번호

# 파일 전송
# 로컬: target/jpa-0.0.1-SNAPSHOT.jar
# 원격: /home/ubuntu/app.jar

Linux/Mac (scp 명령어)

# SCP로 파일 전송
scp target/jpa-0.0.1-SNAPSHOT.jar ubuntu@서버IP:/home/ubuntu/app.jar

# SSH로 서버 접속
ssh ubuntu@서버IP
5

JAR 파일 실행

전송한 JAR 파일을 실행하여 애플리케이션을 구동합니다.

포그라운드 실행 (테스트용)

# 포그라운드에서 실행
java -jar app.jar

# 환경변수와 함께 실행
java -jar app.jar --spring.profiles.active=prod

# 특정 포트로 실행
java -jar app.jar --server.port=8080

백그라운드 실행 (운영용)

# 백그라운드에서 실행
nohup java -jar app.jar > app.log 2>&1 &

# 프로세스 확인
ps aux | grep java

# 로그 확인
tail -f app.log

# 프로세스 종료
kill -9 [PID]

5. 방화벽 및 포트 설정

6

외부 접근 허용

외부에서 애플리케이션에 접근할 수 있도록 포트를 열어줍니다.

# UFW 방화벽 상태 확인
sudo ufw status

# SSH 포트 허용 (이미 열려있어야 함)
sudo ufw allow ssh

# 애플리케이션 포트 허용
sudo ufw allow 8080

# 방화벽 활성화
sudo ufw enable

# 포트 확인
sudo netstat -tlnp | grep :8080

6. 애플리케이션 설정

7

환경별 설정 파일

운영 환경에 맞는 설정을 구성합니다.

# application-prod.yml
spring:
  datasource:
    url: jdbc:mariadb://localhost:3306/jpa
    username: jpa_user
    password: jpa_password
    driver-class-name: org.mariadb.jdbc.Driver
  
  jpa:
    hibernate:
      ddl-auto: validate
    show-sql: false
    properties:
      hibernate:
        format_sql: false

server:
  port: 8080

logging:
  level:
    io.goorm.jpa: INFO
    org.springframework.web: WARN

7. 서비스 등록 (선택사항)

8

systemd 서비스 등록

시스템 부팅 시 자동으로 애플리케이션이 시작되도록 설정합니다.

# 서비스 파일 생성
sudo nano /etc/systemd/system/jpa-app.service

# 서비스 파일 내용
[Unit]
Description=JPA Application
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu
ExecStart=/usr/bin/java -jar /home/ubuntu/app.jar --spring.profiles.active=prod
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target

# 서비스 등록 및 시작
sudo systemctl daemon-reload
sudo systemctl enable jpa-app
sudo systemctl start jpa-app

# 서비스 상태 확인
sudo systemctl status jpa-app
