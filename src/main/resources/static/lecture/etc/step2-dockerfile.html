학습 목표

JAR 파일을 Docker 컨테이너로 패키징하여 일관된 실행 환경을 구축하고 배포 프로세스를 단순화합니다.

  • • Dockerfile 작성 및 이미지 빌드
  • • 컨테이너 실행 및 포트 매핑
  • • 환경변수를 통한 설정 관리
  • • 컨테이너 로그 및 모니터링

1. Docker 설치

1

Docker Engine 설치

우분투 서버에 Docker를 설치합니다.

# 기존 Docker 제거 (있다면)
sudo apt-get remove docker docker-engine docker.io containerd runc

# 패키지 업데이트
sudo apt-get update

# 필요한 패키지 설치
sudo apt-get install ca-certificates curl gnupg lsb-release

# Docker 공식 GPG 키 추가
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

# Docker 저장소 추가
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Docker 설치
sudo apt-get update
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-compose-plugin

# Docker 서비스 시작
sudo systemctl start docker
sudo systemctl enable docker

# 현재 사용자를 docker 그룹에 추가
sudo usermod -aG docker $USER

# 재로그인 후 Docker 버전 확인
docker --version
docker compose version

2. Dockerfile 작성

2

기본 Dockerfile

JAR 파일을 실행할 수 있는 Docker 이미지를 생성합니다.

# Dockerfile
FROM openjdk:11-jre-slim

# 작업 디렉토리 설정
WORKDIR /app

# JAR 파일 복사
COPY target/jpa-0.0.1-SNAPSHOT.jar app.jar

# 포트 노출
EXPOSE 8080

# 애플리케이션 실행
ENTRYPOINT ["java", "-jar", "app.jar"]
3

최적화된 Dockerfile

멀티스테이지 빌드와 보안을 고려한 개선된 Dockerfile입니다.

# 멀티스테이지 빌드
FROM openjdk:11-jre-slim as runtime

# 보안을 위한 사용자 생성
RUN groupadd -r appuser && useradd -r -g appuser appuser

# 작업 디렉토리 설정
WORKDIR /app

# JAR 파일 복사
COPY target/jpa-0.0.1-SNAPSHOT.jar app.jar

# 파일 소유권 변경
RUN chown -R appuser:appuser /app

# 사용자 전환
USER appuser

# 포트 노출
EXPOSE 8080

# 헬스체크 추가
HEALTHCHECK --interval=30s --timeout=3s --start-period=5s --retries=3 \
    CMD curl -f http://localhost:8080/actuator/health || exit 1

# 애플리케이션 실행
ENTRYPOINT ["java", "-jar", "app.jar"]

4. Docker 이미지 빌드

5

이미지 빌드 및 실행

Dockerfile을 사용하여 이미지를 빌드하고 컨테이너를 실행합니다.

1. 이미지 빌드

# 기본 빌드
docker build -t jpa-app .

# 태그와 함께 빌드
docker build -t jpa-app:1.0.0 .

# 빌드 과정 상세 출력
docker build --progress=plain -t jpa-app .

# 이미지 목록 확인
docker images

2. 컨테이너 실행

# 기본 실행
docker run -p 8080:8080 jpa-app

# 백그라운드 실행
docker run -d -p 8080:8080 --name jpa-container jpa-app

# 환경변수와 함께 실행
docker run -d -p 8080:8080 \
  -e SPRING_PROFILES_ACTIVE=prod \
  -e SPRING_DATASOURCE_URL=jdbc:mariadb://host.docker.internal:3306/jpa \
  --name jpa-container jpa-app

# 볼륨 마운트와 함께 실행
docker run -d -p 8080:8080 \
  -v /host/logs:/app/logs \
  --name jpa-container jpa-app

5. 컨테이너 관리

6

컨테이너 상태 관리

실행 중인 컨테이너를 모니터링하고 관리합니다.

컨테이너 상태 확인

# 실행 중인 컨테이너 확인
docker ps

# 모든 컨테이너 확인 (중지된 것 포함)
docker ps -a

# 컨테이너 상세 정보
docker inspect jpa-container

# 컨테이너 리소스 사용량
docker stats jpa-container

# 컨테이너 프로세스 확인
docker top jpa-container

컨테이너 제어

# 컨테이너 시작
docker start jpa-container

# 컨테이너 중지
docker stop jpa-container

# 컨테이너 재시작
docker restart jpa-container

# 컨테이너 삭제
docker rm jpa-container

# 실행 중인 컨테이너 강제 삭제
docker rm -f jpa-container

6. 로그 관리

7

컨테이너 로그 확인

애플리케이션 로그를 확인하고 관리합니다.

# 실시간 로그 확인
docker logs -f jpa-container

# 최근 100줄 로그 확인
docker logs --tail 100 jpa-container

# 특정 시간 이후 로그 확인
docker logs --since "2024-01-01T00:00:00" jpa-container

# 로그 파일로 저장
docker logs jpa-container > app.log 2>&1

# 컨테이너 내부 접속
docker exec -it jpa-container /bin/bash

# 컨테이너 내부에서 로그 확인
docker exec jpa-container tail -f /app/logs/application.log

7. 환경변수 설정

8

환경별 설정 관리

환경변수를 통해 애플리케이션 설정을 외부화합니다.

환경변수 파일 (.env)

# .env
SPRING_PROFILES_ACTIVE=prod
SPRING_DATASOURCE_URL=jdbc:mariadb://host.docker.internal:3306/jpa
SPRING_DATASOURCE_USERNAME=jpa_user
SPRING_DATASOURCE_PASSWORD=jpa_password
SERVER_PORT=8080
LOGGING_LEVEL_IO_GOORM_JPA=INFO

환경변수와 함께 실행

# 환경변수 파일 사용
docker run -d -p 8080:8080 \
  --env-file .env \
  --name jpa-container jpa-app

# 개별 환경변수 설정
docker run -d -p 8080:8080 \
  -e SPRING_PROFILES_ACTIVE=prod \
  -e SPRING_DATASOURCE_URL=jdbc:mariadb://host.docker.internal:3306/jpa \
  --name jpa-container jpa-app

8. 네트워크 설정

9

외부 데이터베이스 연결

호스트의 MariaDB에 연결할 수 있도록 네트워크를 설정합니다.

# 호스트 네트워크 사용 (Linux/Mac)
docker run -d -p 8080:8080 \
  --network host \
  -e SPRING_DATASOURCE_URL=jdbc:mariadb://localhost:3306/jpa \
  --name jpa-container jpa-app

# Windows/Mac에서 host.docker.internal 사용
docker run -d -p 8080:8080 \
  -e SPRING_DATASOURCE_URL=jdbc:mariadb://host.docker.internal:3306/jpa \
  --name jpa-container jpa-app

# 커스텀 네트워크 생성
docker network create jpa-network

# 네트워크에 컨테이너 연결
docker run -d -p 8080:8080 \
  --network jpa-network \
  -e SPRING_DATASOURCE_URL=jdbc:mariadb://db:3306/jpa \
  --name jpa-container jpa-app
