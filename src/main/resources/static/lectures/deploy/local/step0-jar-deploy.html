JAR 배포

IntelliJ → FileZilla → SSH → 웹브라우저 확인

개요 로컬 배포 AWS 배포
서버 준비 JAR 배포 Docker 이론 Dockerfile 배포 Compose 배포

📋 전제 조건

  • ✅ 0단계 서버 준비 완료 (MariaDB + Ubuntu 서버)
  • ✅ IntelliJ에서 프로젝트 빌드 가능
  • ✅ FileZilla 설치됨
  • ✅ Java 21이 서버에 설치됨

1단계: JAR 파일 생성

1

IntelliJ에서 JAR 빌드

프로덕션 환경용 JAR 파일을 생성합니다.

방법 1: IntelliJ Gradle 탭 사용

1. IntelliJ 우측 Gradle 탭 클릭
2. Tasks → build → bootJar 더블클릭
3. 빌드 완료 후 build/libs/ 폴더 확인

방법 2: Terminal 사용

# IntelliJ Terminal에서
./gradlew bootJar

# 또는
gradlew bootJar

JAR 파일 확인

# JAR 파일 위치 확인
ls -la build/libs/

# 예상 출력:
# -rw-r--r-- 1 user user 45678912 Dec 15 10:30 jpa-0.0.1-SNAPSHOT.jar

2단계: 파일 업로드

2

FileZilla로 서버에 업로드

생성한 JAR 파일을 서버에 업로드합니다.

FileZilla 연결 설정

호스트: localhost
사용자명: was
비밀번호: 1234
포트: 2222

업로드 과정

1. 왼쪽 패널 (로컬): build/libs/jpa-0.0.1-SNAPSHOT.jar 선택
2. 오른쪽 패널 (원격): /home/was/app/ 디렉토리로 이동
3. JAR 파일을 오른쪽 패널로 드래그 앤 드롭
4. 업로드 완료 확인

업로드 확인

# SSH로 서버 접속
ssh -p 2222 was@localhost

# 업로드된 파일 확인
ls -la ~/app/
# 예상 출력:
# -rw-r--r-- 1 was was 45678912 Dec 15 10:30 jpa-0.0.1-SNAPSHOT.jar

3단계: 포그라운드 실행

3

SSH로 JAR 실행

애플리케이션을 포그라운드에서 실행하여 로그를 확인합니다.

환경변수 설정 및 실행

# SSH 접속
ssh -p 2222 was@localhost

# 애플리케이션 디렉토리로 이동
cd ~/app

# 환경변수 설정
export DB_PASSWORD=1234

# 포그라운드 실행 (prod 프로필, 포트 8081)
java -jar jpa-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod

웹브라우저에서 확인

1. 웹브라우저 열기
2. 주소창에 입력: http://localhost:8081
3. 애플리케이션 메인 페이지 확인

⚠️ 포그라운드 실행의 문제점

포그라운드 실행은 SSH 연결이 끊어지면 애플리케이션이 종료됩니다. 실제 운영에서는 백그라운드 실행을 사용합니다.

4단계: 백그라운드 실행

4

백그라운드에서 실행

SSH 연결이 끊어져도 애플리케이션이 계속 실행되도록 합니다.

백그라운드 실행

# 애플리케이션 디렉토리로 이동
cd ~/app

# 환경변수 설정
export DB_PASSWORD=1234

# 백그라운드 실행 (로그 파일로 출력)
java -jar jpa-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod > logs/app.log 2>&1 &

# 프로세스 ID 확인
echo $!
# 예상 출력: 12345

실행 상태 확인

# 실행 중인 Java 프로세스 확인
ps aux | grep java

# 포트 사용 확인
netstat -tlnp | grep 8081

# 로그 확인
tail -f ~/app/logs/app.log

✅ 백그라운드 실행의 장점

  • • SSH 연결이 끊어져도 애플리케이션 계속 실행
  • • 로그 파일로 출력 저장
  • • 실제 운영 환경과 동일한 방식

5단계: 최종 확인

5

배포 완료 확인

애플리케이션이 정상적으로 실행되고 있는지 확인합니다.

웹브라우저에서 접속

1. 웹브라우저에서 http://localhost:8081 접속
2. 메인 페이지 정상 로딩 확인
3. API 엔드포인트 테스트

프로세스 관리

# 프로세스 중지
kill -9 [PID]

# 프로세스 재시작
java -jar jpa-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod > logs/app.log 2>&1 &

✅ JAR 배포 완료

🎉 JAR 배포 성공!

이제 다음 기능들이 모두 준비되었습니다:

  • ✅ JAR 파일 생성: IntelliJ에서 빌드 완료
  • ✅ 파일 업로드: FileZilla로 서버 전송
  • ✅ 애플리케이션 실행: 포트 8081에서 실행 중
  • ✅ 웹 접속: http://localhost:8081에서 확인 가능
  • ✅ 백그라운드 실행: SSH 연결 해제 후에도 계속 실행

🔧 문제 해결

자주 발생하는 문제들

1. JAR 파일이 실행되지 않을 때

# Java 버전 확인
java -version

# JAR 파일 권한 확인
ls -la jpa-0.0.1-SNAPSHOT.jar

# 실행 권한 부여
chmod +x jpa-0.0.1-SNAPSHOT.jar

2. 포트가 이미 사용 중일 때

# 포트 사용 확인
netstat -tlnp | grep 8081

# 프로세스 종료
kill -9 [PID]

# 다른 포트로 실행
java -jar jpa-0.0.1-SNAPSHOT.jar --server.port=8082

3. 데이터베이스 연결 오류

# MariaDB 컨테이너 상태 확인
docker ps | grep mariadb

# 네트워크 연결 테스트
ping -c1 mariadb-container
nc -zv mariadb-container 3306
