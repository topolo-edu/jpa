AWS 서비스 비교

서비스 로컬 대응 용도 비용
EC2 Ubuntu 서버 애플리케이션 호스팅 ⭐⭐ (중간)
RDS MariaDB 컨테이너 관리형 데이터베이스 ⭐⭐⭐ (높음)
S3 MinIO 컨테이너 파일 저장소 ⭐ (낮음)
ALB Nginx 컨테이너 로드 밸런서 ⭐⭐ (중간)

비용 최적화 팁

💰 비용 절약 방법

  • • t2.micro 인스턴스 사용 (프리티어)
  • • RDS 대신 EC2에 MariaDB 설치
  • • S3 대신 EC2에 MinIO 설치
  • • ALB 대신 Nginx 사용
  • • 스팟 인스턴스 활용

🎯 실무 권장사항

  • • RDS 사용 (백업, 모니터링)
  • • S3 사용 (확장성, 내구성)
  • • ALB 사용 (고가용성)
  • • CloudWatch 모니터링
  • • Auto Scaling 구성

AWS 계정

  • • 또는 기존 도메인 사용
  • • SSL 인증서 설정
