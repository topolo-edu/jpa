┌─────────────────────────────────────────────────────────────────────────┐

서비스 구성

  • • MinIO: S3 호환 파일 저장소 (포트 9000, 9001)
  • • appnet: 기존 Docker 네트워크 사용

2단계: 우리 프로젝트의 docker-compose.yml 확인

2

실제 프로젝트 파일 확인

우리 프로젝트에 이미 있는 docker-compose.yml 파일을 확인합니다.

우리 프로젝트의 docker-compose.yml

version: "3.9"
services:
  app:
    build: .
    ports:
      - "8083:8082"
    container_name: jpa-app-compose
    restart: unless-stopped
    networks:
      - appnet
    depends_on:
      - minio
    environment:
      - SPRING_PROFILES_ACTIVE=prod
      - DB_PASSWORD=1234
  minio:
    image: minio/minio:latest
    container_name: jpa-minio
    restart: unless-stopped
    ports:
      - "9000:9000"
      - "9001:9001"
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin123
    volumes:
      - minio_data:/data
    command: server /data --console-address ":9001"
    networks:
      - appnet

volumes:
  minio_data:

networks:
  appnet:
    external: true

✅ 주요 설정 확인

  • • 앱 포트: 8083 (외부) → 8082 (내부)
  • • MinIO API: 9000 포트
  • • MinIO 콘솔: 9001 포트
  • • 네트워크: 기존 appnet 사용
  • • 볼륨: minio_data로 데이터 영속성
  • • 프로파일: prod 프로파일 사용 (MariaDB 연결)

3단계: Docker Compose 실행

3

실제 실행하기

우리 프로젝트의 docker-compose.yml을 사용해서 모든 서비스를 실행합니다.

서비스 실행

# 프로젝트 디렉토리에서 실행
cd D:\workspace-goorm\jpa

# 모든 서비스 시작 (백그라운드)
docker-compose up -d

# 또는 로그와 함께 실행
docker-compose up --build

⚠️ 실행 방식 선택

백그라운드 실행 (추천): docker-compose up -d - 콘솔이 즉시 돌아옴, 다른 작업 가능
포그라운드 실행: docker-compose up - 콘솔이 계속 실행 상태로 유지됨

❌ 주의사항

포그라운드 실행 중에는 Ctrl+C로 강제 종료하지 마세요!

  • • 컨테이너가 비정상적으로 중지됨
  • • 데이터 손실 가능성
  • • 다음 실행 시 문제 발생 가능

해결책: 새 터미널에서 docker-compose down으로 정상 종료

실행 확인

# 실행 중인 컨테이너 확인
docker-compose ps

# 또는
docker ps

# 서비스 로그 확인
docker-compose logs -f

# 특정 서비스 로그 확인
docker-compose logs -f app

5단계: MinIO 설정

5

MinIO 버킷 생성 및 설정

MinIO에서 파일 저장을 위한 버킷을 생성하고 권한을 설정합니다.

웹 콘솔에서 설정

1. http://localhost:9001 접속
2. minioadmin / minioadmin123 로그인
3. Buckets 메뉴에서 새 버킷 생성
4. 버킷 정책 설정 (공개/비공개)
5. 파일 업로드 테스트

MinIO 클라이언트로 설정 (선택사항)

# MinIO 클라이언트 컨테이너 실행
docker run --rm -it --network appnet minio/mc:latest bash

# MinIO 서버 연결
mc alias set myminio http://jpa-minio:9000 minioadmin minioadmin123

# 버킷 생성
mc mb myminio/uploads
mc mb myminio/images

# 버킷 정책 설정 (공개 읽기)
mc policy set public myminio/uploads
mc policy set public myminio/images
