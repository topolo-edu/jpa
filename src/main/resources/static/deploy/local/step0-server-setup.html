0단계: 로컬 서버 준비

Docker 기반 MariaDB + Ubuntu 서버 구축

개요 로컬 배포 AWS 배포
서버 준비 JAR 배포 Docker 이론 Dockerfile 배포 Compose 배포

🌐 네트워크 구조도

┌─────────────────────────────────────────────────────────────┐
│                    Docker Host (로컬 PC)                    │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────────┐    ┌─────────────────┐                │
│  │  MariaDB        │    │  Ubuntu Server  │                │
│  │  Container      │    │  Container      │                │
│  │                 │    │                 │                │
│  │  Port: 3306     │◄──►│  Port: 22, 8080 │                │
│  │  (내부)         │    │  (내부)         │                │
│  └─────────────────┘    └─────────────────┘                │
│         │                        │                         │
│         └──────── appnet ────────┘                         │
│                 (Docker Network)                           │
├─────────────────────────────────────────────────────────────┤
│  외부 접속: localhost:3307 (DB) / localhost:2222 (SSH)     │
└─────────────────────────────────────────────────────────────┘

💡 핵심: 같은 네트워크에 연결된 컨테이너들은 컨테이너 이름으로 서로 통신할 수 있습니다.

📋 전제 조건

  • ✅ Docker가 설치되어 있음
  • ✅ 기본적인 명령어 사용 가능
  • ✅ 포트 3307, 2222, 8081이 사용 가능

1단계: MariaDB 설치

1

MariaDB 컨테이너 실행

데이터베이스 서버를 Docker로 실행합니다.

# MariaDB 컨테이너 실행
docker run -d \
  --name mariadb-container \
  -e MYSQL_ROOT_PASSWORD=1234 \
  -p 3307:3306 \
  mariadb:latest

# 실행 확인
docker ps

2단계: 네트워크 생성

2

Docker 네트워크 생성 및 연결

컨테이너들이 서로 통신할 수 있는 네트워크를 생성합니다.

1. 네트워크 생성

# 네트워크 생성
docker network create appnet

# 네트워크 확인
docker network ls

2. MariaDB를 네트워크에 연결

# MariaDB를 새 네트워크에 연결
docker network connect appnet mariadb-container

# 연결 확인
docker network inspect appnet

💡 네트워크란? 컨테이너들이 서로 통신할 수 있는 가상의 통로입니다. 같은 네트워크에 연결된 컨테이너들은 컨테이너 이름으로 서로 찾을 수 있습니다.

3단계: Ubuntu 서버 생성

3

배포용 Ubuntu 서버 실행

애플리케이션을 배포할 Ubuntu 서버를 생성합니다.

# Ubuntu 서버 컨테이너 실행
docker run -d \
  --name deploy-server \
  --network appnet \
  -p 2222:22 \
  -p 8081:8080 \
  -v deploy-data:/home \
  ubuntu:22.04 sleep infinity

# 실행 확인
docker ps

포트 설명

  • • 2222:22 - SSH 접속용
  • • 8081:8080 - 웹 애플리케이션용
  • • deploy-data:/home - 데이터 영속성

4단계: 서버 환경 구성

4

시스템 업데이트 및 패키지 설치

서버에 필요한 기본 패키지들을 설치합니다.

1. 컨테이너 접속

# Ubuntu 서버에 접속
docker exec -it deploy-server bash

# 현재 사용자 확인
whoami   # root

2. 시스템 업데이트 및 패키지 설치

# 시스템 업데이트
apt-get update && apt-get upgrade -y

# 필수 패키지 설치
apt-get install -y \
  openssh-server \
  vim \
  curl \
  wget \
  sudo \
  netcat-openbsd \
  iputils-ping

5단계: SSH 설정

5

SSH 서버 활성화

원격 접속을 위한 SSH 서버를 설정합니다.

1. SSH 서버 실행

# SSH 데몬 준비 및 실행
mkdir -p /run/sshd
ssh-keygen -A
/usr/sbin/sshd

# 실행 확인
pgrep -a sshd

2. 사용자 생성 및 비밀번호 설정

# root 비밀번호 설정
echo "root:admin1234" | chpasswd

# was 사용자 생성
useradd -m -s /bin/bash was
echo "was:1234" | chpasswd

# sudo 권한 추가
usermod -aG sudo was

# 확인
id was

🔒 보안 기본 설정

SSH 설정 파일 수정은 선택사항입니다. 기본 설정으로도 충분히 사용 가능합니다. 실무에서는 /etc/ssh/sshd_config에서 PermitRootLogin no 설정을 권장합니다.

6단계: 연결 테스트

6

내부 및 외부 연결 테스트

SSH 접속과 MariaDB 연결을 테스트합니다.

1. 내부 연결 테스트

# 컨테이너 내부에서 SSH 테스트
ssh -o ConnectTimeout=5 -o StrictHostKeyChecking=no was@localhost
# 비밀번호: 1234

# MariaDB 연결 테스트
ping -c1 mariadb-container
nc -zv mariadb-container 3306

2. 외부 연결 테스트

# 컨테이너에서 나가기
exit

# 호스트에서 SSH 접속
ssh -p 2222 was@localhost
# 비밀번호: 1234

# 또는 root로 접속
ssh -p 2222 root@localhost
# 비밀번호: admin1234

⚠️ SSH 보안 경고

처음 접속 시 다음과 같은 경고가 나타날 수 있습니다:

The authenticity of host '[localhost]:2222' can't be established.
Are you sure you want to continue connecting (yes/no/[fingerprint])? yes

그냥 yes를 입력하면 됩니다!

7단계: DB 연결 확인

7

MariaDB 연결 테스트

Ubuntu 서버에서 MariaDB로 연결할 수 있는지 확인합니다.

1. 네트워크 연결 테스트

# Ubuntu 서버에 SSH 접속
ssh -p 2222 was@localhost

# MariaDB 컨테이너 ping 테스트
ping -c1 mariadb-container

# 결과: PING mariadb-container (172.17.0.2) 56(84) bytes of data.
#       64 bytes from mariadb-container (172.17.0.2): icmp_seq=1 ttl=64 time=0.123 ms

2. 포트 연결 테스트

# MariaDB 포트 연결 테스트
nc -zv mariadb-container 3306

# 성공 시: mariadb-container [172.17.0.2] 3306 (mysql) open
# 실패 시: nc: connect to mariadb-container port 3306 (tcp) failed: Connection refused

3. JDBC 연결 문자열

# Spring Boot application.yml에서 사용
spring:
  datasource:
    url: jdbc:mariadb://mariadb-container:3306/goorm_jpa
    username: root
    password: 1234
    driver-class-name: org.mariadb.jdbc.Driver

🔧 문제 해결

자주 발생하는 문제들

1. SSH 접속이 안 될 때

# 컨테이너 내부에서 SSH 재시작
docker exec -it deploy-server bash
/usr/sbin/sshd

# 포트 확인
docker ps | grep deploy-server

2. MariaDB 연결이 안 될 때

# MariaDB 컨테이너 상태 확인
docker ps | grep mariadb

# 네트워크 확인
docker network inspect appnet

3. 전체 재시작

# 모든 컨테이너 중지 및 삭제
docker stop mariadb-container deploy-server
docker rm mariadb-container deploy-server
