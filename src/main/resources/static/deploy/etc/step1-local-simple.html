🚀 로컬 배포 서버 구축

Docker 기반, MariaDB 연동 (심플 버전)

개요 로컬 서버 2단계: Dockerfile 3단계: Compose 4단계: AWS 5단계: CI/CD

📋 전제 조건

  • ✅ MariaDB 컨테이너가 이미 실행 중 (이름: mariadb-container)
  • ✅ Docker가 설치되어 있음
  • ✅ 기본적인 명령어 사용 가능

1단계: 네트워크 확인

1

기존 MariaDB 컨테이너 확인

MariaDB가 실행 중인지 확인합니다.

# 실행 중인 컨테이너 확인
docker ps

# mariadb-container가 보여야 함
# CONTAINER ID   IMAGE      COMMAND                  CREATED        STATUS        PORTS                    NAMES
# abc123def456   mariadb    "docker-entrypoint.s…"   2 hours ago    Up 2 hours    0.0.0.0:3306->3306/tcp   mariadb-container

2단계: 배포 서버 컨테이너 생성

2

Ubuntu 컨테이너 실행

배포용 Ubuntu 서버 컨테이너를 생성합니다.

# 배포 서버 컨테이너 생성
docker run -d \
  --name deploy-server \
  --network bridge \
  -p 2222:22 \
  -p 8081:8080 \
  -v deploy-data:/home \
  ubuntu:22.04 sleep infinity

# 컨테이너 실행 확인
docker ps

포트 설명

  • • 2222:22 - SSH 접속용 (호스트 2222 → 컨테이너 22)
  • • 8081:8080 - 웹 애플리케이션용 (호스트 8081 → 컨테이너 8080)
  • • deploy-data:/home - 데이터 영속성을 위한 볼륨

3단계: 컨테이너 내부 설정

3

컨테이너 접속 및 기본 설정

컨테이너 내부에 접속하여 필요한 패키지를 설치합니다.

1. 컨테이너 접속

# 컨테이너 내부 접속
docker exec -it deploy-server bash

# 현재 사용자 확인
whoami   # root

2. 시스템 업데이트 및 패키지 설치

# 시스템 업데이트
apt-get update && apt-get upgrade -y

# 필수 패키지 설치
apt-get install -y \
  openssh-server \
  vim \
  curl \
  wget \
  sudo \
  netcat-openbsd \
  iputils-ping

4단계: SSH 설정

4

SSH 서버 설정 및 실행

SSH 서버를 설정하여 외부에서 접속할 수 있도록 합니다.

1. SSH 서버 설정

# SSH 데몬 준비
mkdir -p /run/sshd
ssh-keygen -A

# SSH 데몬 실행
/usr/sbin/sshd

# 실행 확인
pgrep -a sshd

2. 사용자 생성 및 비밀번호 설정

# root 비밀번호 설정
echo "root:admin1234" | chpasswd

# was 사용자 생성
useradd -m -s /bin/bash was
echo "was:1234" | chpasswd

# sudo 권한 추가
usermod -aG sudo was

# 확인
id was

5단계: SSH 접속 테스트

5

외부에서 SSH 접속

호스트에서 컨테이너로 SSH 접속을 테스트합니다.

1. 컨테이너에서 나가기

# 컨테이너에서 나가기
exit

2. 호스트에서 SSH 접속

# was 사용자로 접속
ssh -p 2222 was@localhost
# 비밀번호: 1234

# 또는 root로 접속
ssh -p 2222 root@localhost
# 비밀번호: admin1234

⚠️ SSH 보안 경고 해결

처음 접속 시 다음과 같은 경고가 나타날 수 있습니다:

The authenticity of host '[localhost]:2222' can't be established.
Are you sure you want to continue connecting (yes/no/[fingerprint])? yes

그냥 yes를 입력하면 됩니다!

6단계: MariaDB 연결 테스트

6

네트워크 연결 확인

배포 서버에서 MariaDB 컨테이너로 연결할 수 있는지 확인합니다.

1. 네트워크 연결 테스트

# SSH로 배포 서버 접속 후
ssh -p 2222 was@localhost

# MariaDB 컨테이너 ping 테스트
ping -c1 mariadb-container

# 결과: PING mariadb-container (172.17.0.2) 56(84) bytes of data.
#       64 bytes from mariadb-container (172.17.0.2): icmp_seq=1 ttl=64 time=0.123 ms

2. 포트 연결 테스트

# MariaDB 포트 연결 테스트
nc -zv mariadb-container 3306

# 성공 시: mariadb-container [172.17.0.2] 3306 (mysql) open
# 실패 시: nc: connect to mariadb-container port 3306 (tcp) failed: Connection refused

3. JDBC 연결 문자열

# Spring Boot application.yml에서 사용
spring:
  datasource:
    url: jdbc:mariadb://mariadb-container:3306/goorm_jpa
    username: your_username
    password: your_password

7단계: Java 설치 (선택사항)

7

Java 21 설치

JAR 파일을 직접 실행할 수 있도록 Java를 설치합니다.

# SSH로 배포 서버 접속
ssh -p 2222 was@localhost

# Java 21 설치
sudo apt-get update
sudo apt-get install -y openjdk-21-jdk

# Java 버전 확인
java -version

# JAVA_HOME 설정
echo 'export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64' >> ~/.bashrc
echo 'export PATH=$JAVA_HOME/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

# 환경변수 확인
echo $JAVA_HOME

🔧 문제 해결

자주 발생하는 문제들

1. SSH 접속이 안 될 때

# 컨테이너 내부에서 SSH 재시작
docker exec -it deploy-server bash
/usr/sbin/sshd

# 포트 확인
docker ps | grep deploy-server

2. MariaDB 연결이 안 될 때

# MariaDB 컨테이너 상태 확인
docker ps | grep mariadb

# 네트워크 확인
docker network ls
docker network inspect bridge

3. 컨테이너 재시작

# 컨테이너 중지 및 삭제
docker stop deploy-server
docker rm deploy-server

# 다시 생성
docker run -d \
  --name deploy-server \
  --network bridge \
  -p 2222:22 \
  -p 8081:8080 \
  -v deploy-data:/home \
  ubuntu:22.04 sleep infinity
