핵심 개념

🐳 Docker

  • • 컨테이너: 애플리케이션과 의존성을 패키징
  • • 이미지: 컨테이너의 템플릿
  • • 네트워크: 컨테이너 간 통신
  • • 볼륨: 데이터 영속성 보장

☁️ AWS

  • • EC2: 가상 서버 (로컬 Ubuntu 대응)
  • • RDS: 관리형 데이터베이스 (로컬 MariaDB 대응)
  • • S3: 객체 저장소 (로컬 MinIO 대응)
  • • ALB: 로드 밸런서 (로컬 Nginx 대응)
